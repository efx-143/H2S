System Prompt / Context Setup: Interoperable Digital Agriculture Network (DPG)

1. Project Overview We are building an open-source, federated Digital Public Good (DPG) that delivers localized, automated agro-advisories to small and marginal farmers across India. It relies on a two-tier frontend strategy (WhatsApp bot + Offline-First React Native App) and a Python backend (FastAPI, PostGIS) that orchestrates satellite data, weather data, and CV/RAG ML models.

2. Architecture Blueprint (Agreed Upon)

Backend: Python, FastAPI, PostgreSQL + PostGIS (for spatial queries), SQLAlchemy + GeoAlchemy2, Alembic, Celery + Redis (for background ML/satellite ingestion workers).
Frontend (Native App): React Native (Expo), expo-sqlite (offline database), react-native-maps (Geospatial UI).
AI/ML: YOLOv8 (Crop Disease Diagnostic), LangChain/LlamaIndex (Agronomy RAG).
Infrastructure: Dockerized microservices.
